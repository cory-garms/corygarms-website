In mobile terrestrial forestry inventory, capturing the 3D geometry of standing timber requires processing massive point clouds directly in the field. Under our USDA STTR Phase I/II project, **CUTMAP**, we developed a multi-sensor rig combining mobile Livox LiDAR with stereo vision to perform autonomous stem mensuration and silvicultural thinning prescriptions.

One of the most persistent bottlenecks in field point cloud analysis is isolating individual tree stems from dense understory foliage, low branches, and slope ground returns—and computing accurate Diameter at Breast Height (DBH) and 3D lean vectors in real time on embedded edge compute.

---

### The Problem: Irregular Bark, Branch Clutter, and Lean

Traditional circular cross-section slicing assumes stems are perfectly upright vertical columns. But mature conifer stands (such as Douglas-fir or Lodgepole pine) frequently exhibit stem curvature, sweep, and directional phototropic lean:

1. **Horizontal Slicing Bias**: Slicing an inclined cylinder horizontally produces an ellipse rather than a circle, leading to systematic overestimation of basal area and timber volume by up to $14\%$.
2. **Branch Noise**: Lateral branches and needles corrupt standard least-squares circle fits.
3. **Edge Compute Constraints**: Mobile robotic platforms cannot stream raw 100k-pt/s point clouds to the cloud; point clouds must be segmented and solved on-rig at 10–15 Hz.

---

### Geometry-Constrained RANSAC Formulation

To robustly fit a 3D cylinder to candidate stem clusters, we parameterize the cylinder model by seven degrees of freedom: a base point on the axis $\mathbf{p}_0 \in \mathbb{R}^3$, a unit orientation vector $\mathbf{a} \in \mathbb{R}^3$ ($\|\mathbf{a}\| = 1$), and a positive radius $r \in [r_{\min}, r_{\max}]$:

$$
d(\mathbf{p}_i, \mathcal{C}) = \left| \|(\mathbf{p}_i - \mathbf{p}_0) \times \mathbf{a}\| - r \right| < \epsilon_{\text{dist}}
$$

To prevent RANSAC from evaluating non-stem geometry (such as planar rocks or horizontal branches), we enforce a strict surface normal constraint:

$$
|\mathbf{n}_i \cdot \mathbf{a}| \le \sin(\theta_{\text{thresh}})
$$

Points on the surface of a cylinder must have outward normals approximately orthogonal to the cylinder's longitudinal axis.

```python
import numpy as np

def fit_constrained_cylinder_ransac(points, normals, max_iter=200, dist_thresh=0.015, rad_bounds=(0.08, 0.95)):
    """
    Edge-optimized RANSAC cylinder estimator with normal orientation constraints.
    """
    best_inliers = []
    best_params = None
    r_min, r_max = rad_bounds
    
    n_pts = len(points)
    if n_pts < 10:
        return None
        
    for _ in range(max_iter):
        # Sample 2 seed points with divergent normal vectors
        idx1, idx2 = np.random.choice(n_pts, 2, replace=False)
        p1, p2 = points[idx1], points[idx2]
        n1, n2 = normals[idx1], normals[idx2]
        
        # Axis vector is orthogonal to both surface normals
        axis = np.cross(n1, n2)
        axis_norm = np.linalg.norm(axis)
        if axis_norm < 1e-4:
            continue
        axis /= axis_norm
        
        # Enforce near-vertical prior (-45 deg to +45 deg lean)
        if abs(axis[2]) < np.cos(np.radians(45)):
            continue
            
        # Project points onto plane perpendicular to estimated axis
        proj_pts = points - np.outer(np.dot(points - p1, axis), axis)
        
        # Fast 2D circle fit on projected 3-point subset
        radius = np.linalg.norm(proj_pts[idx1] - proj_pts[idx2]) / 2.0
        if not (r_min <= radius <= r_max):
            continue
            
        center = (proj_pts[idx1] + proj_pts[idx2]) / 2.0
        
        # Measure orthogonal distances to candidate cylinder
        dists = np.abs(np.linalg.norm(proj_pts - center, axis=1) - radius)
        inliers = np.where(dists < dist_thresh)[0]
        
        if len(inliers) > len(best_inliers):
            best_inliers = inliers
            best_params = (center, axis, radius)
            
    return best_params, best_inliers
```

### Performance on Edge Hardware

By downsampling candidate point clusters with a 1.5 cm voxel grid and pre-filtering normals via KD-tree PCA covariance matrices, the constrained RANSAC solver converges in **under 12 milliseconds per stem** on embedded Jetson Orin compute.
