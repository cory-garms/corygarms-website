When space telescopes like NASA's Neil Gehrels Swift Observatory conduct rapid target-of-opportunity pointings, the Ultraviolet/Optical Telescope (UVOT) often operates without active guide-star tracking. Instead, the instrument records individual ultraviolet photon events with microsecond timestamps directly into raw detector coordinates $(\text{RAWX}, \text{RAWY}, t)$.

Under nominal conditions, spacecraft drift is under a pixel. However, during high reaction-wheel momentum or attitude limit cycling, the telescope bore-sight wanders erratically—sometimes tracing out serpentine streaks exceeding 450 detector pixels ($> 12''$). Traditional pipeline coaddition smears point sources into hollow ribbons, obliterating light curves and astrometric centers.

To solve this for our archival study of AGN NGC 4395 and the wider Swift UVOT archive, we engineered **UNJITR** (*UV/Optical Nonlinear Jitter & Instability Trajectory Recovery*). Here is how the core phase registration engine recovers diffraction-limited spatial resolution without requiring external star catalogs.

---

### Slicing the Photon Continuum

Because UVOT operates in photon-counting mode rather than integrating frame mode, we are free to discretize time arbitrarily. We slice the event stream into overlapping temporal windows with cadence $\Delta t = 0.15\,\text{s}$ and window half-width $\tau = 1.0\,\text{s}$:

$$
I_k(x, y) = \sum_{i \in \Omega_k} w(t_i - t_k) \, \delta(x - x_i, y - y_i)
$$

where $w(\Delta t)$ is a Hann smoothing kernel that prevents temporal aliasing at slice boundaries.

<Alert type="info" title="Why 1.0s Windows Matter">
Earlier iterations attempted 5.0-second correlation slabs. In Regime 3 (high-frequency limit cycling with a ~15-second period), a 5.0-second window blurs the rapid velocity turnaround points, leaving residual dumbbell artifacts. Dropping to $\tau = 1.0\,\text{s}$ at $6.7\,\text{Hz}$ resolution fully resolves the turnaround dynamics.
</Alert>

### Hoisted 2D FFT Cross-Correlation

For each temporal slab $I_k$, we compute the normalized 2D spatial cross-correlation with a stable reference template $I_{\text{ref}}$:

$$
C_k(u, v) = \mathcal{F}^{-1} \left[ \frac{\mathcal{F}[I_k] \cdot \mathcal{F}[I_{\text{ref}}]^*}{|\mathcal{F}[I_k] \cdot \mathcal{F}[I_{\text{ref}}]^*|^\gamma} \right]
$$

where $\gamma = 0.35$ provides optimal whitening between pure phase correlation ($\gamma = 1.0$) and standard cross-correlation ($\gamma = 0.0$).

Because the reference template FFT $\mathcal{F}[I_{\text{ref}}]^*$ is invariant across the exposure, it is precomputed and hoisted out of the correlation loop:

```python
import numpy as np
from scipy.signal import savgol_filter

def compute_drift_offset(slab_fft, ref_fft_conj, gamma=0.35):
    """
    Sub-pixel offset registration via 2D hoisted Fourier cross-correlation.
    """
    # Cross-power spectrum
    cross_power = slab_fft * ref_fft_conj
    mag = np.abs(cross_power)
    
    # Fractional whitening
    if gamma > 0:
        cross_power /= np.maximum(mag ** gamma, 1e-12)
        
    corr_surface = np.real(np.fft.ifft2(cross_power))
    corr_surface = np.fft.fftshift(corr_surface)
    
    # Locate integer grid peak
    v_idx, u_idx = np.unravel_index(np.argmax(corr_surface), corr_surface.shape)
    
    # Sub-pixel parabolic peak interpolation
    dx = fit_parabola_1d(corr_surface[v_idx, u_idx-1 : u_idx+2])
    dy = fit_parabola_1d(corr_surface[v_idx-1 : v_idx+2, u_idx])
    
    center_y, center_x = np.array(corr_surface.shape) // 2
    return (u_idx + dx - center_x), (v_idx + dy - center_y)

def fit_parabola_1d(three_pts):
    """Parabolic vertex estimator across 3 adjacent correlation values."""
    left, center, right = three_pts
    denom = 2.0 * (2.0 * center - left - right)
    if abs(denom) < 1e-9:
        return 0.0
    return (left - right) / denom
```

---

### Parabolic Vertex Interpolation

The integer pixel peak $(\hat{u}, \hat{v})$ of $C_k(u, v)$ provides coarse registration. To achieve true diffraction-limited restoration, we estimate the fractional shift $(\delta x, \delta y)$ by fitting continuous 1D parabolas through the 3-point cardinal neighbors:

$$
\delta x = \frac{C(\hat{u}-1, \hat{v}) - C(\hat{u}+1, \hat{v})}{2 \left[ 2 C(\hat{u}, \hat{v}) - C(\hat{u}-1, \hat{v}) - C(\hat{u}+1, \hat{v}) \right]}
$$

This closed-form estimator avoids costly iterative non-linear optimization while achieving $\pm 0.10\,\text{pixel}$ precision across photon densities down to $0.05\,\text{photons/px/s}$.

---

### Trajectory Inversion & Astrometric Results

Once the continuous trajectory $(\Delta X(t), \Delta Y(t))$ is regularized via a Savitzky-Golay polynomial filter to remove Poisson photon noise, every raw event $(X_i, Y_i, t_i)$ in the original FITS table is shifted to its restored physical sky coordinate:

$$
X_{\text{restored}} = X_i - \Delta X(t_i)
$$
$$
Y_{\text{restored}} = Y_i - \Delta Y(t_i)
$$
