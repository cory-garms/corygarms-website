### Ingestion Pipeline: Statcast Pitch-by-Pitch

The data engine runs on an automated daily pipeline using Python and `pybaseball`. Every morning at 06:00 ET, a cron script queries MLB’s Statcast API for the previous night's pitch-level tracking data:

* **Trajectory Physics**: Initial release velocity ($v_0$), release point $(x_0, y_0, z_0)$, plate crossing velocities, and perceived vertical/horizontal movement (IVB & HB).
* **Batted-Ball Profiles**: Exit velocity ($v_{\text{exit}}$), launch angle ($\theta$), expected batting average ($\text{xBA}$), and expected weighted on-base average ($\text{xwOBA}$).

```python
from pybaseball import statcast_pitcher, schedule_and_record
import pandas as pd
import numpy as np

def compute_bullpen_fatigue_score(pitch_log_df, lookback_days=4):
    """
    Calculate non-linear fatigue penalty based on pitch counts and rest intervals.
    Weights decay exponentially over a rolling 4-day window.
    """
    decay_weights = {0: 1.0, 1: 0.65, 2: 0.35, 3: 0.15}
    fatigue_index = 0.0
    
    for day_lag, weight in decay_weights.items():
        daily_pitches = pitch_log_df[pitch_log_df['days_ago'] == day_lag]['pitch_count'].sum()
        # Non-linear penalty kicking in heavily beyond 20 pitches
        stress_factor = daily_pitches * (1.0 + max(0, daily_pitches - 20) * 0.05)
        fatigue_index += weight * stress_factor
        
    # Scale into 0-100 Availability Index (100 = Fully Fresh, < 30 = Redlined)
    availability = max(0.0, min(100.0, 100.0 - (fatigue_index * 1.8)))
    return round(availability, 1)
```

### Modeling Bullpen Fatigue & Availability

Reliever performance does not degrade linearly with raw pitch counts. A reliever throwing 18 pitches two days in a row experiences significantly more neuromuscular strain than one throwing 36 pitches in a single outing followed by two days of rest.

Dirty Water computes an **Availability Score** ($A \in [0, 100]$) for every arm in the Boston bullpen by combining:
1. **Exponential Recency Weighting**: Outings within the last 24 hours carry 3× the fatigue weight of outings from 72 hours prior.
2. **Leverage Multipliers**: High-leverage innings (pLI $> 1.5$ with runners in scoring position) add an extra 20% metabolic penalty due to elevated pitch intensity.
3. **Velocity Drift**: Deviations between a pitcher’s four-seam fastball velocity in consecutive games and their 30-day baseline serve as an empirical signal of fatigue.
